# 奶茶店收银系统 - 启动指引

## 系统要求
- JDK 11 或更高版本
- Maven 3.6+
- Node.js 16+
- npm 或 yarn

## 启动步骤

### 第一步：启动后端服务

1. 打开终端，进入后端目录：
```bash
cd backend
```

2. 编译并启动SpringBoot应用：
```bash
mvn clean spring-boot:run
```

或者先打包再运行：
```bash
mvn clean package -DskipTests
java -jar target/pos-system-1.0.0.jar
```

3. 验证后端是否启动成功：
   - 访问 http://localhost:8080/api/products
   - 应该能看到商品列表JSON数据

### 第二步：启动前端服务

1. 打开新终端，进入前端目录：
```bash
cd frontend
```

2. 安装依赖：
```bash
npm install
```

3. 启动开发服务器：
```bash
npm run dev
```

4. 访问前端页面：
   - 打开浏览器访问 http://localhost:3000
   - 应该能看到奶茶店收银系统界面

## 功能验证

### 1. 商品浏览
- 页面加载后应该能看到4个分类标签：奶茶、果茶、奶盖、咖啡
- 每个分类下有对应的商品列表

### 2. 选择商品和规格
- 点击任意商品卡片
- 底部弹出规格选择窗口
- 选择糖度（无糖/少糖/半糖/正常糖）
- 选择冰度（去冰/少冰/正常冰/热饮）
- 点击"加入购物车"

### 3. 购物车
- 加入购物车后会有成功提示
- 底部显示已选商品数量和总金额
- 点击"去结算"进入结算页面

### 4. 结算支付
- 在结算页面可以调整商品数量或删除商品
- 选择支付方式（现金/微信/支付宝）
- 点击底部支付按钮
- 支付成功后自动跳转到小票页面

### 5. 小票打印
- 小票页面显示订单详情
- 可以点击"打印小票"打印订单
- 或返回首页继续下单

### 6. 日结报表
- 点击首页右上角"日结报表"
- 可以选择日期查看当日销售情况
- 显示订单数量、总金额、各支付方式金额
- 显示当日订单明细列表

## 常见问题

### 问题1：前端显示"加载商品失败"
**原因**：后端服务未启动或端口不正确
**解决**：
1. 确保后端已启动并运行在8080端口
2. 检查浏览器控制台是否有CORS错误
3. 重新启动后端服务

### 问题2：下单时提示"下单失败"
**原因**：后端API无法访问
**解决**：
1. 检查后端服务是否正常运行
2. 查看浏览器控制台Network标签的请求状态
3. 访问 http://localhost:8080/api/products 验证API

### 问题3：数据库文件问题
**原因**：旧数据库可能导致初始化失败
**解决**：
1. 删除backend目录下的 milktea_pos.db 文件
2. 重启后端服务，会自动重新创建数据库并初始化商品数据

### 问题4：前端依赖安装失败
**原因**：npm源问题或网络问题
**解决**：
```bash
# 尝试使用淘宝镜像
npm config set registry https://registry.npmmirror.com
npm install
```

## 开发模式注意事项

1. 后端运行在 http://localhost:8080
2. 前端运行在 http://localhost:3000
3. 前端通过Vite代理转发API请求到后端
4. 数据库文件 milktea_pos.db 会自动创建在backend目录下
5. 系统启动时会自动初始化15种商品数据
